데이터가 웹사이트가 되기까지

국토교통부에서 아파트 실거래 데이터를 받아 정리한 뒤, 사람이 보는 화면으로 내보내기까지의 전체 흐름입니다. 왼쪽에서 오른쪽으로 읽으시면 됩니다.

왜 미리 계산해 두나요?

GitHub Pages에는 계산을 대신해 줄 서버가 없습니다. 파일을 그대로 내려주기만 하죠. 그래서 무거운 계산은 내 컴퓨터에서 파이썬으로 미리 끝내고, 그 결과만 .json 파일로 만들어 올려둡니다.

왜 파일을 둘로 나눴나요?

전부 한 번에 받으면 7.6MB라 첫 화면이 느려집니다. 그래서 요약본(88KB)만 먼저 받아 화면을 그리고, 검색이나 세부 필터를 쓸 때 비로소 상세 데이터를 받습니다.

주황색 상자가 목적지

이 모든 과정이 향하는 곳입니다. 예산을 넣으면 갈 수 있는 동네를 추려주는, 사람이 실제로 쓰는 화면이죠.
