# sesac-web

새싹캠퍼스 파이썬과정 — 서울·경기 아파트 실거래 대시보드

> **"내 예산으로 어디 갈 수 있나?"**
> 실거주할 집을 찾는 사람이 자기자본과 대출한도를 넣으면,
> 갈 수 있는 지역과 단지를 한 화면에서 좁혀갈 수 있는 정적 대시보드입니다.

🔗 **[대시보드 보기](https://sojung-yun404.github.io/sesac-web/dashboard.html)** · [소개 페이지](https://sojung-yun404.github.io/sesac-web/)

---

## 기능

- **예산 컨트롤** — 자기자본 + 대출한도로 상한을 자동 계산, 하한 슬라이더로 하자 매물 제외
- **지역 랭킹** — 서울 25개 구와 경기 47개 시·군·구를 **한 표에 동등하게** 놓고 중위가로 줄세워 예산 가능 여부를 판정
- **월별 추이** — 12개월 시세 흐름 위에 예산선을 겹쳐 표시
- **단지 검색** — 아파트 이름으로 찾아 평형별 시세와 개별 실거래 내역 확인
- **필터** — 평형(국평 기준), 거래 시기, 최소 거래건수, 건축년도

판정 기준은 **중위가**입니다. 극단적인 고가·저가 거래 몇 건에 흔들리지 않아
체감 시세에 가장 가깝기 때문입니다.

## 구조

```
├── index.html              소개 페이지
├── dashboard.html          대시보드 (단일 페이지)
├── data/
│   ├── regions.json          지역별 사전 집계 (88KB, 첫 화면용)
│   ├── trades-seoul.json     서울 거래 원본 (2.4MB, 지연 로드)
│   └── trades-gyeonggi.json  경기 거래 원본 (5.2MB, 지연 로드)
├── scripts/
│   ├── fetch_molit.py      국토부 API 수집 (resume 지원)
│   └── build_data.py       수집 결과 → JSON 전처리
├── docs/
│   ├── PRD.md              제품 요구사항
│   └── DATA_CONTRACT.md    데이터 스키마 규격
└── analyze.py              성북구 단일 분석 (초기 습작)
```

GitHub Pages에는 서버가 없으므로, 집계는 **빌드 타임(Python)** 과 **브라우저(JS)** 로 나눠 처리합니다.
첫 화면은 88KB짜리 사전 집계만으로 즉시 그리고, 사용자가 필터를 건드리거나 검색할 때
거래 원본(총 7.6MB)을 지연 로드해서 브라우저에서 정확히 재계산합니다.
근사치가 아니라 정확한 값이 나오면서도 첫 로드는 가볍습니다.

## 데이터 재생성

수집 원본(`data/raw/`)은 저장소에 포함되어 있지 않습니다.

```bash
export MOLIT_API_KEY='공공데이터포털_인증키'
python3 scripts/fetch_molit.py   # 72개 지역 × 12개월 = 864회 호출, 약 8분
python3 scripts/build_data.py    # data/*.json 생성
```

인증키는 [공공데이터포털](https://www.data.go.kr)에서 *국토교통부_아파트 매매 실거래가 상세 자료*
활용신청 후 발급받습니다 (즉시 자동승인). `.env` 파일에 `MOLIT_API_KEY=...` 로 넣어도 됩니다.

`fetch_molit.py`는 중간에 끊겨도 재실행하면 이미 받은 (지역, 월)은 건너뜁니다.
두 스크립트 모두 파이썬 표준 라이브러리만 사용합니다 (pandas 없음).

## 기술

의존성 없이 브라우저에서 바로 도는 정적 사이트입니다.

- Vanilla JS + HTML/CSS, 빌드 도구 없음
- 차트는 인라인 SVG를 직접 생성 (외부 차트 라이브러리 없음)
- 디자인은 [Montage](https://github.com/wanteddev/montage-web) 디자인 토큰 기반
- 전처리는 Python 표준 라이브러리
